# Spintelligence

**Beyblade X counter intelligence.** Spintelligence studies the Beyblade you are about to face and tells you which model beats it, using only the official published part stats. Log the Beyblades you own and it picks the best counter *from your own arsenal*.

| Platform | Get it | Guide |
| --- | --- | --- |
| Web app (iPhone, Android, any browser) | https://chromechris.github.io/beyblade-counter/ | [Web app on iPhone and Android](Web-app-on-iPhone-and-Android.md) |
| Android app | `Spintelligence-debug.apk` | [Installing on Android](Installing-on-Android.md) |
| Windows app | `Spintelligence.exe` | [Installing on Windows](Installing-on-Windows.md) |
| Command line (Python) | `python -m beycounter` | [Building from source](Building-from-source.md) |

## At a glance

- 248 official models and 260 parts across the BX, UX and CX lines plus Hasbro releases. Stats as published by Takara Tomy / Hasbro, transcribed by the [Beyblade Wiki](https://beyblade.fandom.com) (CC BY-SA).
- Works offline on every platform. Nothing leaves the device: no server, no account, no telemetry.
- The same scoring model runs in the app and in the Python command line.
- Version 1.0, October 2026. Source code: https://github.com/chromechris/beyblade-counter
